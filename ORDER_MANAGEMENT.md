# Управление заказами - Новые возможности

## Добавленные функции

### 1. Отображение адреса доставки
Администраторы теперь видят полный адрес доставки при просмотре заказа:
- 📍 Адрес доставки
- 🗺️ Координаты (если предоставлены)
- 📱 Телефон клиента

### 2. Статусы заказов
Добавлены новые статусы с автоматическими оповещениями:

| Статус | Описание | Оповещение клиенту |
|--------|----------|-------------------|
| `new` | Новый заказ | - |
| `payment_pending` | Ожидание чека | - |
| `accepted` | Чек принят | ✅ Подтверждение |
| `cooking` | Готовится | 🍳 Время готовности |
| `ready` | Готов | ✅ Передан курьеру |
| `courier_assigned` | У курьера | 🚚 Информация о курьере |
| `delivered` | Доставлен | ✅ Подтверждение + баллы |

### 3. Оповещения клиента

#### При начале приготовления:
```
🍳 Ваш заказ готовится!

Заказ #1 передан на кухню.
Время приготовления: ~20 минут.
Ожидаемая готовность: 16:20

Следите за статусом в разделе 'Мои заказы'.
```

#### При готовности:
```
✅ Ваш заказ готов!

Заказ #1 передан курьеру.
Время готовности: 16:20

Курьер уже выехал к вам! 🚚
```

#### При передаче курьеру:
```
🚚 Заказ передан курьеру!

Заказ #1 в пути.
Курьер: Иван

Скоро будет у вас! ⏱️
```

#### При доставке:
```
✅ Заказ доставлен!

Заказ #1 успешно доставлен.
Сумма: 500₽
🎁 Начислено баллов: 50

Будем рады видеть вас снова! 😊
```

### 4. Фото курьера
Администратор может отправить фото курьера клиенту:
1. Нажать "📸 Фото курьера" в деталях заказа
2. Отправить фото курьера с заказом
3. Фото автоматически отправится клиенту

### 5. Управление через админ-панель

#### Список заказов:
```
📋 Управление заказами

🆕 Заказ #1 | @username
   💰 500₽ | Статус: cooking
   📍 ул. Пушкина, д. 10
   ⏰ Готовность: 16:20
   🕒 15.05 15:30
```

#### Детали заказа:
Все информация о заказе с кнопками управления статусом:
- Адрес доставки
- Координаты
- Телефон клиента
- Состав заказа
- Время приготовления
- Курьер

## Работа с заказами

### Для администратора:

1. **Просмотр списка заказов**:
   - Админ-панель → 📋 Заказы
   - Все заказы с краткой информацией

2. **Детали заказа**:
   - Нажмите на номер заказа
   - Полная информация и кнопки управления

3. **Управление статусами**:
   - `accepted` → `cooking`: "🍳 Начать приготовление"
   - `cooking` → `ready`: "✅ Заказ готов"
   - `ready` → `courier_assigned`: "🚚 Передать курьеру"
   - `courier_assigned` → `delivered`: "✅ Подтвердить доставку"

4. **Отправка фото курьера**:
   - В деталях заказа: "📸 Фото курьера"
   - Отправьте фото
   - Автоматическая отправка клиенту

### Автоматические действия:

- **При переводе в `cooking`**: Устанавливается время готовности (+20 минут)
- **При переводе в `delivered`**: 
  - Начисляются баллы лояльности (1 балл за 10₽)
  - Освобождается курьер
  - Предлагается оставить отзыв

## База данных

### Таблица `orders` - новые поля:
```sql
estimated_ready_time TEXT  -- Ожидаемое время готовности
actual_ready_time TEXT     -- Фактическое время готовности
courier_id INTEGER         -- ID назначенного курьера
```

### Таблица `couriers`:
```sql
status TEXT DEFAULT 'offline'  -- offline/online/busy
current_lat REAL               -- Текущие координаты
current_lon REAL
last_update TEXT               -- Время последнего обновления
```

## Примеры использования

### Пример 1: Полный цикл заказа
```
1. Заказ создан → payment_pending
2. Админ принимает чек → accepted (клиент уведомлен)
3. Админ начинает приготовление → cooking (клиент уведомлен, время: 16:20)
4. Заказ готов → ready (клиент уведомлен)
5. Передан курьеру → courier_assigned (клиент уведомлен)
6. Отправлено фото курьера → клиент видит фото
7. Доставка подтверждена → delivered (клиент уведомлен, баллы начислены)
```

### Пример 2: Фото курьера
```
Админ: Нажимает "📸 Фото курьера"
Бот: "Отправьте фото курьера с заказом"
Админ: Отправляет фото
Бот: Отправляет фото клиенту с текстом "Ваш заказ в пути!"
```

## Рекомендации

1. **Настройка времени приготовления**: Измените `timedelta(minutes=20)` в `admin_order_cooking()` на реальное среднее время
2. **Курьеры**: Добавьте курьеров через админ-панель перед началом работы
3. **Баллы лояльности**: Коэффициент начисления (1 балл = 10₽) можно настроить в коде
4. **Отзывы**: После доставки клиенту предлагается оставить отзыв
