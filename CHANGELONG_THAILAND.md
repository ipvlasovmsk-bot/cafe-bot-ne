
### 4. Примеры изменений

#### До:
```python
text += f"💰 {dish[3]}₽\n"
date_str = datetime.fromisoformat(created).strftime("%d.%m %H:%M")
```

#### После:
```python
from app.utils.thai_time import format_price, format_thailand_time

text += f"💰 {format_price(dish[3])}\n"
date_str = format_thailand_time(datetime.fromisoformat(created), "%d.%m %H:%M")
```

## 📝 Примечания

1. **Часовой пояс**: Таиланд использует UTC+7 круглый год (нет перехода на летнее время)
2. **Валюта**: Можно изменить в `app/config.py` через `CURRENCY_SYMBOL`
3. **Форматы**: Все форматы времени настраиваются через параметры функций форматирования
4. **БД**: Даты и времена сохраняются в ISO формате, конвертация только для отображения
